## التشغيل السريع

```bash
git clone <repo> && cd systemix
cp .env.example .env      # عبّي TOKEN و CLIENT_ID و CLIENT_SECRET و OWNER_ID
npm install
npm start
```

ثم افتح `http://localhost:3000` ← **تسجيل الدخول بـ Discord** ← اختر سيرفرك.

**إعداد Developer Portal (مرة وحدة):**
1. Bot: انسخ التوكن وفعّل `Server Members Intent` و`Message Content Intent`.
2. OAuth2: انسخ `Client ID`، واضغط Reset Secret وانسخ `Client Secret`.
3. OAuth2 ← Redirects: أضف `PUBLIC_URL/auth/callback` (مثلاً `http://localhost:3000/auth/callback`).
4. أضف البوت لسيرفرك برابط الدعوة من **لوحة المالك** (صلاحية Administrator، ورتبة البوت الأعلى).

## الإعدادات (`.env`)

| المتغير | الوصف |
|---|---|
| `TOKEN` | توكن البوت (مطلوب) |
| `CLIENT_ID` / `CLIENT_SECRET` | لتسجيل الدخول بـ Discord |
| `OWNER_ID` | ايدي المالك، أو **عدة ملاك مفصولين بفاصلة** (`111,222`). يفعّل لوحة المالك والاشتراكات. فاضي = كل السيرفرات تشتغل بدون قيود |
| `PORT` / `PUBLIC_URL` | منفذ الويب والرابط العام (https في الإنتاج). على Render يُؤخذ تلقائياً |
| `DATA_DIR` | مكان حفظ البيانات (الافتراضي `./data`) |

## نظام الاشتراكات

* السيرفرات اللي يملكها أي واحد من الملاك (`OWNER_ID`) **مجانية دائماً**، وكل مالك يدخل لوحة المالك.
* السيرفر الجديد يبدأ **متوقفاً** حتى تفعّله من `/owner` (أو تجربة مجانية من الإعدادات).
* السيرفر المتوقف/المنتهي: البوت يبقى فيه لكنه **لا يعمل**، والأوامر ترد برسالة تواصل، وتوصل صاحب السيرفر رسالة (في اللوج + خاص).
* تنبيه قبل الانتهاء، ومغادرة تلقائية اختيارية، وتنبيه لك لما ينضاف البوت لسيرفر جديد.

## هيكل المشروع

```
src/index.js            النواة: تخزين، اشتراكات، حماية، أوامر، ويب
src/features/           ميزات مستقلة (logs, bin, starboard, tempvoice, statchannels, tools)
public/                 dashboard.html, owner.html, view.html, logo
tests/                  اختبارات (node:test) بمكتبات وهمية، بدون اتصال بديسكورد
deploy/                 setup-vps.sh, Caddyfile.example
render.yaml             نشر بضغطة على Render (Blueprint)
docs/DEPLOY.md          دليل النشر 24 ساعة (Render / VPS / Docker)
```

كل ميزة جديدة تُكتب كوحدة في `src/features/` تستقبل `ctx` (client, app, auth, cfg, save, ...) وتسجّل أحداثها ومساراتها بنفسها.

## النشر على Render

ارفع الريبو (Private) ← Render ← **New ← Blueprint** ← عبّي `TOKEN` و`CLIENT_ID` و`CLIENT_SECRET` و`OWNER_ID`. التفاصيل (والخطة المجانية وحدودها) في [`docs/DEPLOY.md`](docs/DEPLOY.md).

## الأمان

* ترويسات أمان، حد طلبات، حماية CSRF (same-origin)، وكوكيز `HttpOnly` + `Secure` على https.
* روابط الدخول ذات الاستخدام الواحد، وجلسات OAuth لمدة 7 أيام.
* لا تُحفظ أي أسرار في الكود؛ كلها في `.env` (مستبعد من Git).

## الحدود المعروفة

* ديسكورد لا يسمح للبوتات باسترجاع الرابط المميز؛ البوت يكشف ويعاقب فقط.
* الاسترجاع يعيد الرتب والرومات وصلاحياتها، لا الرسائل.
* التخزين ملف JSON (مناسب لعشرات السيرفرات)؛ لعدد كبير انقله لقاعدة بيانات.
